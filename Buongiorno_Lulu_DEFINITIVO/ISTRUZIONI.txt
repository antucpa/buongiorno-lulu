BUONGIORNO LULÙ — INSTALLAZIONE UNICA

1. Apri il repository antucpa/buongiorno-lulu su GitHub.
2. Seleziona Add file > Upload files.
3. Carica genera.py, README.md, index.html, giornale.pdf, giornale.jpg, edizione.json e la cartella .github/workflows/quotidiano.yml, conservando la struttura delle cartelle. NOTA: GitHub via browser può non caricare correttamente cartelle nascoste: in tal caso crea manualmente il file .github/workflows/quotidiano.yml, oppure usa GitHub Desktop per importare la cartella completa.
4. Commit changes.
5. Settings > Actions > General > Workflow permissions: Read and write permissions.
6. Actions > Buongiorno Lulu - giornale quotidiano > Run workflow.
7. Controlla https://antucpa.github.io/buongiorno-lulu/ dopo la pubblicazione.

IMPORTANTE: il generatore produce la pagina quotidiana ma la qualità giornalistica dipende dai feed e non è revisionata. Il collegamento finale all'ESP32 richiede lo sketch IPP che hai già usato con successo.
